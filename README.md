Política de Privacidade – Como melhorar o mundo
Última atualização: 06/05/2026

A presente Política de Privacidade descreve como o aplicativo Como melhorar o mundo (“App”), desenvolvido por Instituto Colmeia (“nós”), trata os dados dos usuários.

Ao utilizar o App, você concorda com esta Política.

1. Dados que coletamos
Atualmente, o App não coleta, armazena ou compartilha dados pessoais dos usuários.

2. Finalidade do uso dos dados
Como não há coleta de dados pessoais nesta versão, não há tratamento de dados para fins de perfilamento, marketing ou compartilhamento com terceiros.

3. Anúncios e serviços de terceiros
Atualmente, o App não exibe anúncios e não utiliza serviços de terceiros para análise de uso.

4. Compartilhamento de dados
Nós não vendemos dados pessoais e, nesta versão, não realizamos compartilhamento de dados pessoais com terceiros.

5. Armazenamento e retenção
Como não há coleta de dados pessoais nesta versão, não há retenção de dados pessoais de usuários.

6. Segurança
Adotamos medidas técnicas e organizacionais razoáveis para manter a segurança do App.

7. Direitos do usuário (LGPD e legislações aplicáveis)
Nos termos da legislação aplicável, você pode solicitar informações sobre eventual tratamento de dados pessoais, quando aplicável.

8. Privacidade de crianças
O App é destinado ao público geral. Caso seja identificado tratamento indevido de dados de menores, tomaremos as medidas cabíveis para remoção.

9. Transferência internacional de dados
Nesta versão, não há transferência internacional de dados pessoais, pois não há coleta de dados pessoais.

10. Alterações desta Política
Podemos atualizar esta Política periodicamente. A versão mais recente estará sempre disponível na URL informada na loja do aplicativo.
